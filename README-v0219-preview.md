# v0.2.19 독립 웹 테스트

완성된 통합 로컬 제작 도구의 8대 변경을 v0.2.18 고정 소스 `4fddbc5`에 적용한 실험판입니다. `main`과 기존 v0.2.18 게임 파일은 변경하지 않습니다.

- 테스트 경로: `/luck-dungeon/preview/v0.2.19/`
- 기존 게임 경로: `/luck-dungeon/`
- 별도 브랜치: `feature/game-v0.2.19-preview`
- 새 승급 8종, 운빨 조합·연계 확장, 순수 공격 연속타, 가격 인하 11종, 접이식 설명과 클리어 표시를 포함합니다.
- 기존 이미지·모험가 5종·음원을 유지합니다. 신규 카드 그림은 원래 계열의 그림을 재사용합니다.
- 테스트 기록과 이니셜 랭킹은 이 기기·브라우저에만 저장합니다. 기존 플레이 기록과 다른 저장 키를 사용합니다. 앱 데이터를 삭제하면 사라질 수 있으므로 내 플레이 기록에서 JSON/CSV를 내보낼 수 있습니다.
- 테스트판에는 기존 클라우드 설정을 넣지 않으며 CSP의 `connect-src 'none'`으로 외부 기록 전송을 차단합니다. 정식 랭킹이나 기존 데이터베이스에 반영되지 않습니다.
- 이 빌드는 기능을 직접 확인하기 위한 통합 실험판입니다. R30 클리어율과 신규 수치의 밸런스를 확정한 정식판은 아닙니다.

## 재현과 검증

```sh
python prepare_site.py
python build_v0219_preview.py
python -m unittest test_v0219_preview -v
```

원래 제공된 `Build_LUCK_v0.2.19.py`는 `v0219_patch.py`로 보관합니다. 웹 빌더가 그 게임 규칙 패치 함수를 호출하고, 모바일의 큰 단일 HTML 다운로드를 피하도록 이미지·음원을 개별 파일로 제공합니다.

빌드 보고서는 기존 런타임 65개 파일의 해시가 유지되는지 검사합니다. 자동 검사는 모바일 시작→상점→전투, 모험가 선택, 신규 승급, 순수 공격 연속타, 로컬 기록·랭킹 분리, 6전략의 실제 엔진 플레이를 포함합니다. 결과와 화면은 Actions 아티팩트로 남깁니다.

배포는 기존 v0.2.18 런타임을 그대로 둔 `_site`에 테스트 경로를 추가하는 방식입니다. 기존 브랜치의 배포를 나중에 다시 실행하면 테스트 경로가 제거될 수 있으므로 재게시할 때 이 미리보기 워크플로도 실행해야 합니다. PR은 검토용 Draft로 유지하며 자동 병합하지 않습니다.
