# LUCK Dungeon v0.2.17 — UI / 전략 / 순위 초기 구현

## 변경 목록

- 기본 상점 1번째 카드 = 손재주(4원), 2번째 = 삼연격(5원). 기존 카드 성능·재고 규칙은 유지.
- 랜덤 풀에 `spark`(행운의 조각, 4원, 한정 구매)를 추가. 랜덤 상점 8종 선정 규칙 유지, R1 출현 보장 없음.
- 운빨 승급 `p_luck_charm`(동전+주사위, 자원 5), `p_luck_fate`(길운의 부적+혼돈 상자, 자원 8·보석 1). 행운 58%→66%, 중립 26%→23%, 불운 16%→11%, 파괴 3%→2%. 레전드 보상 가능. 확정 강화를 만들지 않음.
- 상점 기본/랜덤의 시각적 경계 강화. 승급 목록을 **자원, 공격, 행동, 운빨** 그룹으로 구분. 카드 도감은 같은 카드 ID를 한 장만 표시, 덱/손패 수량을 별도 표시.
- 상단 고정 디버프 버튼: 활성 적 수, 예상 공격력 감소; 팝업은 콤보·연계 수치, 보호로 막은 점수(실제 소모량), 손실 수치(게임 시작 이후 누계)를 표시. 보호 점수와 실피해량의 단위는 서로 다름.
- 사망 화면: 적 수 / 최대 적 수, 누적 HP / 허용 HP, 디버프 손실, 원인별 전략 팁, 점수 구성 공개. 점수 공식은 `v1`로 기존 가중치 유지.
- 시작 화면: 일간, 주간(월요일 시작), 월간, 누적, 무한모드 최고 R의 **기기 내** 순위. 게임 종료 및 R30 공식전 종료 시 이니셜 2~6글자 등록 가능. 기존 `luck_dungeon_manual_runs_v0216` 로컬 데이터도 계속 사용.

## 랭킹 운영 범위 — 중요

현재는 **브라우저 로컬 순위 초안**입니다. Supabase `manual_runs`는 계정별 비공개 기록이고, 클라이언트에서 보내는 점수만으로 전 세계 공개 랭킹을 생성하면 누구나 점수를 조작할 수 있습니다. **공개 온라인 순위는 아직 구현하지 않았으며**, 서버측 리플레이 검증·비정상 점수 탐지·이니셜 필터링·검증 완료 기록만 공개하는 RLS 구조가 준비된 후 도입해야 합니다. UI에서도 전역 순위로 오인할 표현은 사용하지 않았습니다.
